# Car Showroom

This is my first web project, a car showroom website I built with HTML and CSS while learning front-end development.

Live site: https://khaledhosny188-jpg.github.io/car-showroom/

## What's in it

- A home section with a welcome message and navigation links (Home, Cars, Offers)
- Car cards showing the photo, price, and discount
- A dark and gold color theme
