
# Car Showroom 🚗

## About The Project
This is a simple Car Showroom website created using HTML and CSS.

The website displays different cars with their pictures, descriptions, prices, and discounts.

## Project Features
- Simple and attractive design.
- Display different car images.
- Show car names and descriptions.
- Display car prices.
- Show discounts on some cars.
- Navigation menu to move between sections.
- Smooth scrolling.
- Background image.
- Hover effects on car cards.

## Cars Available
1. Toyota
2. Kia Soul
3. Kia K3

## Technologies Used
- HTML
- CSS

## How To Run
1. Download or open the project folder.
2. Open the `index.html` file in your browser.
3. Enjoy browsing the cars!
