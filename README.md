# Car Showroom

A responsive car showroom website built with HTML and CSS.

## Live Demo

https://khaledhosny188-jpg.github.io/car-showroom/

## Features

- Modern dark and gold design
- Responsive layout that works on mobile and desktop
- Car cards with images, price, and discount
- Smooth scrolling navigation (Home, Cars, Offers)

## Built With

- HTML5
- CSS3
