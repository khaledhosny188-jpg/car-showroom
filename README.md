# Car Showroom

A simple car showroom landing page built with HTML and CSS. 

## Features 
- Responsive card layout using flexbox and media queries 
- Dark theme with gold accents
- Smooth scrolling navigation
- Hover effect on car card (transform and transition)

## Project Structure 
- `index.html`- main page 
- `style.css`- styles
- `images/`- car photos and background 

## How to Run
1. Download or clone the project.
2. Open `index.html` in your browser.

Or use the **Live Server** extension in VS Code:
1. Right-click `index.html` and choose **Open with Live Server**.
2. The page opens at `http://127.0.0.1:5500/index.html`.
